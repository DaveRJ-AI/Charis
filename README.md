# Charis Legacy Foundation Site Starter

Starter website rebuild for Charis Legacy Foundation using React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build for Netlify

```bash
npm run build
```

Publish directory:

```bash
dist
```

## Notes

- Logo file is currently stored at `public/images/charis-logo.png`
- Main content placeholders are in `src/data/siteContent.js`
- Page files are in `src/pages/`
- Global styling is in `src/styles/index.css`
